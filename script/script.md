# 用腾讯 WorkBuddy 配一个钉钉打卡提醒助手 · 旁白（9 镜）

脚本编剧定稿，由配音师代推。合成：tts-1、alloy、speed 1.25、wav。

| 文件 | 镜头 | 旁白 |
|---|---|---|
| s0 | 钩子 | 每天最怕啥？忘打卡。今天用腾讯 WorkBuddy，两分钟配个到点就喊你打卡的 AI 助手。先说清楚：它不替你打卡，卡还得你本人打。 |
| s1 | 安装 | 去 WorkBuddy 官网下载，Windows 和 Mac 都有，装好用微信扫码登录。 |
| s2 | 钉钉建机器人 | 打开钉钉，建个只有自己的提醒群。群设置点机器人，添加自定义机器人，安全设置选自定义关键词，填「打卡」，复制 Webhook。 |
| s3 | 新建定时任务 | 回到 WorkBuddy，点左侧定时任务，新建旁边的箭头，选从任务新建，一句话就行。 |
| s4 | 说一句话 | 比如：每个工作日早上 8 点 50 和晚上 6 点，用 curl 往这个钉钉 Webhook 发一条打卡提醒，内容带上打卡两个字。 |
| s5 | 确认配置 | 它会自动建好任务，重复选每周一到五。权限记得选完全访问，不然没人点确认，任务会卡住。电脑经常关机，就建成云端任务。 |
| s6 | 验证 | 点立即运行试一次。钉钉群马上收到该打卡了，运行记录显示成功，就算配好了。 |
| s7 | 合规提醒 | 注意三点：别让 AI 代打卡，也别用虚拟定位，这违反考勤制度，钉钉也会判异常；Webhook 别外传；本地任务要电脑开着、客户端别退出。 |
| s8 | 结尾 | 到点提醒，你只管伸手打卡。觉得有用就收藏，转给那个总忘打卡的同事。 |

念法：WorkBuddy 念 Work Buddy；Webhook 全片念英文；curl 念「科尔」；「8 点 50」念「八点五十」。
